# Emergency Reserve

A simple web app for tracking an emergency reserve: food, hygiene & medical, pet and household goods.

- Add items with a category and expiry date
- Items expired or expiring within 30 days are flagged at the top
- Filter by category, edit expiry dates, delete items
- Data is saved in your browser (localStorage), so it stays on the device you use

## Run it

Open `index.html` in a browser. No build step or dependencies.

## Host on GitHub Pages

Push to a repo, then Settings > Pages > Deploy from a branch > `main` / root.
